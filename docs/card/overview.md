# Card overview

Thermostat Pro Timeline card is a visual 24-hour timeline planner.

## What you can do

- Add or double-click to edit/add heating/cooling periods for each room.
- Two timeline views:
  - All rooms for one day
  - One room across multiple days
- Optional features:
  - Weekdays grouping (weekday/weekend, Sat/Sun, all 7 days)
  - Profiles per room
  - Presence and Away mode logic
  - Holidays (calendar/manual)
  - Seasonal schedules (summer/winter)
  - Open Window Detection (OWD)
  - Boiler control (backend)
  - Per-room defaults + labels + merges
  - Color ranges for temp intervals

> Most of the “big” features are controlled in YAML as *_enabled: true and then fully configured in the card UI (especially profiles/presence/away combos).

All YAML can be created via the UI, so you don’t need to edit the YAML code at all.
