# ❄️ Thermostat Pro Timeline

Thermostat Pro Timeline is a Home Assistant solution composed of:

- A custom integration (`thermostat_timeline`) that provides a shared schedules store, background control, backup/restore, and a small HTTP API used by the card.
- A Lovelace card (`custom:thermostat-pro-timeline`) for visual 24-hour timeline planning, with advanced features like weekdays, profiles, presence and holidays.

## Highlights

- 🗓️ Timeline planner for multiple rooms
- 📅 Per-weekday schedules + two timeline views
- 🏷️ Profiles (named schedules per room)
- 👥 Presence schedules + Away mode with delays/combos
- 🎉 Holidays (calendar entities or manual date lists)
- 🌤️ Seasonal schedules (Summer/Winter)
- 🪟 Open Window Detection (OWD)
- 🔥 Boiler control in the backend
- 🗄️ Shared multi-user storage + multi-instance support
- 💾 Backup/restore with slots + auto backup
- 🚀 Automatic resource install (copies JS to `/local`)
